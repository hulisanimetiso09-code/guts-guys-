## Part 3 Implementation Highlights
- **JavaScript Enhancements:** Interactive Leaflet.js map, dynamic live search filter across all cards, full-screen gallery lightbox modal, and collapsible accordions.
- **Form Controls & Validation:**
  - `enquiry.html`: Validates South African phone numbers and instantly computes price estimates and turn-around times upon submission.
  - `contact.html`: Validates form entries and compiles structured `mailto` messages for direct client communication.
- **Search Engine Optimization (SEO):** Clean semantic structure, H1-H3 header hierarchies, descriptive alt tags, meta titles, descriptions, keywords, `robots.txt`, and `sitemap.xml`.
