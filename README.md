# GUTS & GUYS - Premium Men's Apparel Website

## Project Overview
This repository contains the complete responsive website for **GUTS & GUYS**, an exclusive men's fashion atelier operating in Limpopo, South Africa. The platform displays menswear collections, custom fitting appointment forms, runway events, and store location maps.

## Key Features
- **HTML5 Semantic Structure:** Formatted using standard semantic HTML elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<fieldset>`, `<footer>`).
- **Standard Navigation Schema:** Preserves exact naming and multi-page routing structure (`index.html`, `aboutus.html`, `menu.html`, `events.html`, `enquiry.html`, `contact.html`).
- **Custom Order & Fitting Form:** Includes structured user inputs for requested garments, sizing notes, and order urgency.
- **Embedded Interactive Map:** Displays store location details on the contact page.

## Directory Structure
- `index.html`: Main landing showcase highlighting suit collections and brand strengths.
- `pages/aboutus.html`: Brand story, tailor craftsmanship standards, and material quality guarantees.
- `pages/menu.html`: Complete itemized menswear catalogue covering suits, casual streetwear, and accessories.
- `pages/events.html`: Seasonal runway show dates, VIP trunk shows, and styling masterclasses.
- `pages/enquiry.html`: Online fitting request form with customer fields and textareas.
- `pages/contact.html`: Boutique physical address, phone details, and embedded Google Maps frame.
- `css/style.css`: Unified stylesheet controlling design, spacing, layout grids, and responsiveness.
